Winning and Giving Up

Every game is dealt so that it can be won, but a wrong move can make that impossible. The game checks after each move, and tells you when there is no longer any way to win, so you can undo (if the level allows) or give up.

Give Up hands the game to the computer. It finishes the game in front of you, taking back your moves first if that is the only way to win. A game you give up counts as a loss.

Starting a new game, or restarting, while a game is in progress also counts as a loss.
